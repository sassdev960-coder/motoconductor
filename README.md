# Moto Movil - App del Conductor

App HTML/JS para conductores. Se compila como APK con Capacitor + GitHub Actions.

## Como compilar

1. Subir el codigo a GitHub (branch main)
2. Ir a la pestana "Actions"
3. Esperar ~5 min
4. Descargar el APK desde "Artifacts"

## Instalar en el telefono

1. Descargar el APK
2. Habilitar "Instalar apps desconocidas"
3. Instalar y aceptar permisos (ubicacion + camara)

## Debug

La app tiene una consola integrada: toca el engranaje abajo a la derecha.
